# RSI

RSI通过计算特定时期内价格涨幅和跌幅的平均值，来衡量资产的动量强度。它是一个介于0到100之间的震荡器，用于识别超买和超卖状态。

`RSI = 100 - 100 / (1 + RS)`
其中 `RS` = `(期内上涨日平均涨幅 / 期内下跌日平均跌幅)`



## 信号

### 1. 超买超卖（Oversold & Overbought）

- **时间片**：1H、4H（适用于波动性市场）
- **参数**：RSI(14)，阈值 30/70 或 20/80
- **信号简称**：
    - **RBO** = RSI Overbought（RSI > 70 或 80）
    - **RSO** = RSI Oversold（RSI < 30 或 20）
- **规则**：
    - 当RSI下穿超卖线后，再次上穿该线时，视为**潜在买入信号**。
    - 当RSI上穿超买线后，再次下穿该线时，视为**潜在卖出信号**。
- **直觉**：价格急剧单向运动后，动量衰竭，大概率会发生均值回归。

### 2. 背离交易（Divergence Trading）（重要）

#### 看跌背离

**这是发生在上升趋势末期的警示信号。**

- **形态特征**：
    1. **价格**：创出一个**更高的高点**。
    2. **RSI指标**：却创出一个**更低的高点**。
- **市场含义**：
    - 价格虽然涨得更高了，但推动上涨的买方力量（动量）实际上比前一次上涨时要弱。
    - 这就像是“虚张声势”，上涨缺乏后劲，可能预示着上升趋势即将结束，反转下跌的可能性增加。
- **交易逻辑**：
    - 当你识别出看跌背离时，**这是一个强烈的预警信号，而不是一个立即做空的指令**。
    - 它告诉你：**不要再追高了！** 并且应该考虑在阻力位附近减仓或平掉多头仓位。
    - 真正的做空信号，需要等待价格本身给出确认，例如：出现看跌的K线形态（如乌云盖顶、看跌吞没）、价格跌破关键的上升趋势线或前一个低点。

### 3. 失效摆动（Failure Swing）

- **时间片**：1H、4H
- **参数**：RSI(14)
- **信号简称**：
    - **RSI_FSB** = Failure Swing Bottom（底部失效摆动，看涨）
    - **RSI_FST** = Failure Swing Top（顶部失效摆动，看跌）
- **规则**：
    - **RSI_FSB**：RSI < 30 → 反弹突破30 → 回撤未破30 → 再次向上时**买入**。
    - **RSI_FST**：RSI > 70 → 回落跌破70 → 反弹未破70 → 再次向下时**卖出**。
- **直觉**：这是对经典超买超卖信号的强化，通过二次确认来过滤假信号，提高入场成功率。

### 4. 中线交叉（Centerline Crossover）

- **时间片**：1H、4H
- **参数**：RSI(14)，中线50
- **信号简称**：
    - **RBC** = RSI Bullish Cross（RSI上穿50）
    - **RBC** = RSI Bearish Cross（RSI下穿50）
- **规则**：
    - RBC → **买入信号**
    - RBC → **卖出信号**
- **直觉**：RSI 50中线代表多空力量平衡点，上穿意味着多头动量占据主导，下穿则意味着空头动量占据主导。
