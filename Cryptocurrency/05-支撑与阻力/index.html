    量化交易05-支撑与阻力

    发表于 2025-10-03 分类于 笔记 本文字数： 1.8k 阅读时长 ≈ 2 分钟

    支撑与阻力是技术分析的基石。其他所有指标，最终都是为了回答一个问题：“当前的支撑或阻力是否会有效？”

    核心概念

    • 支撑：价格下跌时，可能遇到买方力量增强、卖方力量减弱，从而使价格暂停下跌或反弹的水平。可以想象成 “地板”。
    • 阻力：价格上涨时，可能遇到卖方力量增强、买方力量减弱，从而使价格暂停上涨或回落的水平。可以想象成 “天花板”。

    其背后的核心心理是市场记忆：交易者会记住之前价格在某个水平反转过，从而在未来再次到达该水平时采取类似行动。

    水平支撑与阻力

    这是最基本、最有效的一种。

    1. 识别方法

    • 前期高点：尤其是多次测试未能突破的高点，构成强阻力。
    • 前期低点：尤其是多次测试未能跌破的低点，构成强支撑。
    • 成交密集区：价格在某个区域横盘整理了很长时间，这个区域积累了大量的成交量，之后无论价格从哪个方向离开，这个区域都会成为强大的支撑或阻力。

    2. 市场行为与交易逻辑

    • 反弹与回落：在支撑位附近，寻找价格止跌反弹的信号（如看涨K线形态、RSI底背离）作为买入机会。在阻力位附近则相反。
    • 突破与回踩：当价格强势突破阻力位后，角色转换 发生：原来的阻力位变成了新的支撑位。当价格回踩这个新支撑位并企稳时，是极佳的买入时机。跌破支撑位后同理。

    动态支撑与阻力

    这类支撑阻力不是水平的，而是随着时间移动的，它们能更好地捕捉趋势。

    1. 趋势线

    • 画法：
      • 上升趋势线：连接连续两个或多个逐渐抬高的低点。
      • 下降趋势线：连接连续两个或多个逐渐降低的高点。
    • 用法：趋势线本身就是一个动态的支撑（上升趋势线）或阻力（下降趋势线）。价格回踩趋势线是趋势交易者的经典入场点。

    2. 移动平均线

    • 像EMA， SMA这样的均线，本身就是非常有效的动态支撑阻力。
    • 用法：在上升趋势中，价格回踩关键均线（如20期或50期EMA）是常见的加仓或入场点。在下降趋势中，均线则构成反弹的阻力。

    心里价位

    例如，股票价格的整十、整百元关口（如500），股指的整千点（如3000点），比特币的整万美金关口。这些位置因为引人注目，所以容易形成支撑阻力。

    心理价位不是基于复杂的计算，而是基于人类最基础的认知习惯：我们天生对“整数”和“规整的数字”更敏感，更容易记住它们，并以此作为决策参考。

    在市场中，这种集体心理会形成一种无形的力量，导致价格在接近这些关键整数时，买卖订单会自然聚集，从而使价格行为在此处出现停顿、反弹或突破。

    市场行为与交易逻辑

    • 作为阻力：
      • 行为：当价格接近一个重要的心理价位（如$100）时，会有交易者开始提前卖出以锁定利润，也会有做空者在此处开仓。这会增加卖压。
      • 交易思路：在价格首次接近心理阻力位时，不要急于追高。应观察是否有价格动能减弱（如出现长上影线、看跌吞没等K线形态）和成交量放大的迹象。可以将其作为减仓或尝试做空的区域。
    • 作为支撑：
      • 行为：当价格从高处回落至一个心理价位时，会有交易者认为“便宜了”而开始买入，形成买盘支撑。
      • 交易思路：在价格首次跌至心理支撑位时，观察是否有止跌信号（如锤子线、看涨吞没）。可以将其作为潜在买入区域。
    • 突破的关键：
      • 假突破很常见：价格可能会瞬间刺破心理关口，但很快又回落回来。
      • 确认真突破：需要一个强烈的确认信号。这通常包括：
        1. 强劲的K线：一根坚决的大阳线（对于向上突破） 或大阴线（对于向下跌破），收盘价牢牢站在心理关口之上/之下。
        2. 成交量的放大：突破时必须伴随成交量的显著放大，代表有真正的资金在推动。
        3. 角色转换：一旦被有效突破，原来的心理阻力位就会转变为未来的心理支撑位（反之亦然）。例如，股价有效突破100就会成为一个强大的支撑。

    斐波那契回撤

    斐波那契回撤工具基于斐波那契数列（一个每个数字都是前两个数字之和的数列：0， 1, 1, 2, 3, 5, 8, 13, 21...）。这个数列在自然界中无处不在，而交易者相信金融市场也受其影响。

    其核心思想是：在一波显著的价格运动（上涨或下跌）之后，其反向的回调运动往往会在一系列关键的斐波那契比例处遇到支撑或阻力并暂停/结束。

    关键水平与画法

    • 核心水平（按重要性排序）：
      • 61.8%：“黄金分割”回撤位，这是最重要、最受关注的水平。回调在此处止跌反弹的概率极高。
      • 38.2%：次重要的水平。
      • 50.0%：虽然不是一个严格的斐波那契比率，但它是一个非常符合市场心理的“半途点”，因此被广泛使用，效果显著。
      • 23.6%：浅度回调位，表明趋势非常强劲。
      • 78.6%：深度回调位，如果跌破此位，通常意味着这不是回调，而是趋势反转的开始。
