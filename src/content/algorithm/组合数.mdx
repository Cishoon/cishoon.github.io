直接计算组合数 $C(n, m)$ 的模板，利用 $C(n,m) = \frac{n!}{m!(n-m)!}$ 的递推形式逐项计算，避免溢出。

```c++
i64 C(i64 n, i64 m) {
    if (m < 0 || m > n) return 0;
    if (m > n / 2) m = n - m;
    i64 res = 1;
    for (int i = 1; i <= m; i++) {
        res = res * (n - i + 1) / i;
    }
    return res;
}
```

$$C(n,m) = \prod_{i=1}^{m} \frac{n-i+1}{i}$$

因为连续 $i$ 个整数中必有一个能被 $i$ 整除，所以每步整除都是精确的，不会丢精度。
