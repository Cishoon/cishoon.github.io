核心思想：**与其让每个提问者向右逐个找答案，不如让每个新元素到来时，主动去回答之前所有它能回答的提问者。**

我不太喜欢“单调栈”这个名字。单调栈是在用上述思想解决问题时，经常会被构造出来的数据结构。单调栈这个名字不能概括上述思想。

---

先看例题，力扣[739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)。

> 给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。
>
> **示例 1:**
>
> ```
> 输入: temperatures = [73,74,75,71,69,72,76,73]
> 输出: [1,1,4,2,1,1,0,0]
> ```
>
> **示例 2:**
>
> ```
> 输入: temperatures = [30,40,50,60]
> 输出: [1,1,1,0]
> ```
>
> **示例 3:**
>
> ```
> 输入: temperatures = [30,60,90]
> 输出: [1,1,0]
> ```





最朴素的想法：对于元素 $i$ ，遍历 $j \in [i+1, n)$ ，找到第一个 $a[j] > a[i]$ ，此时 $j - i$ 即为答案。找不到答案为 $0$ 。由此可以轻松写出代码：

```c++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& a) {
        int n = a.size();
        vector<int> ans(n, 0);
        
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (a[j] > a[i]) {
                    ans[i] = j - i;
                    break;
                }
            }
        }
    
        return ans;
    }
};
```

元素 $6,5,4,3,2$ 都要遍历到 $7$ 。$5,4,3,2$ 均被多次遍历。存在重复。

为什么会被多次遍历呢？因为同一个元素在不同轮次中扮演的角色不同：

1. 当它是 <font color='blue'>蓝色</font> 元素时，它是「提问者」——正在寻找右边第一个比自己大的值。
2. 当它是 <font color='red'>红色</font> 元素时，它是「候选者」——被拿来和蓝色元素比较，看自己够不够大。



能不能让每个元素只当一次「候选者」？换个思路：**与其让提问者向右寻找答案，不如让每个新元素到来时，主动去回答之前所有它能回答的提问者**。

具体来说，我们维护一个栈，里面存放所有还没找到答案的提问者（的下标）。当新元素 $a[j]$ 到来时：

- 如果 $a[j]$ 比栈顶元素大，说明栈顶的提问者找到答案了，弹出并记录答案 $j - \text{栈顶下标}$。
- 重复上述过程，直到栈为空或栈顶元素 $\geq a[j]$。
- 最后把 $j$ 压入栈中，它也成为一个新的提问者。

因为栈里的元素从底到顶是递减的（想想为什么？如果后来的元素更大，前面比它小的早就被弹出了），所以这个结构叫做单调栈。

每个元素最多入栈一次、出栈一次，总时间复杂度 $O(n)$。

然后写出代码：

```c++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& a) {
        int n = a.size();
        vector<int> ans(n, 0);
        stack<int> st;

        for (int j = 0; j < n; j++) {
            while (!st.empty() && a[j] > a[st.top()]) {
                int i = st.top();
                st.pop();
                ans[i] = j - i;
            }
            st.push(j);
        }

        return ans;
    }
};

```

举一反三，再看一题[84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)。

对于每一个柱子，向左向右分别找到第一个比自己矮的，就能算出包含这个柱子的最大面积。

**向右找到第一个比自己矮的**，每个柱子都要当这个「提问者」。那不如让每个柱子主动回答左边的柱子。

```c++
class Solution {
public:
    int largestRectangleArea(vector<int>& a) {
        int n = a.size();

        vector<int> right(n, n); // right[i] 表示i右边第一个比i矮的坐标。
        vector<int> left(n, -1); // left[i]  表示i左边第一个比i矮的坐标。

        stack<int> st;
        for (int i = 0; i < n; i++) {
            while(!st.empty() && a[i] < a[st.top()]) {
                right[st.top()] = i;
                st.pop();
            }
            st.push(i);
        }
        while(!st.empty()) st.pop();

        for (int i = n - 1; i >= 0; i--) {
            while(!st.empty() && a[i] < a[st.top()]) {
                left[st.top()] = i;
                st.pop();
            }
            st.push(i);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans = max(ans, (right[i] - left[i] - 1) * a[i]);
        }
        return ans;
    }
};
```
